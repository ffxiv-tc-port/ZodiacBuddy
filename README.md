# Zodiac Buddy

讓 2.0 版本黃道武器（黃道勇士、阿尼瑪、本我）製作流程更輕鬆的小工具。

## 功能

- **阿尼瑪收集**：點擊阿尼瑪任務書中的任務項目，自動傳送到最近的乙太之光；點擊副本項目則自動開啟該副本的組隊報名視窗
- **黃道武器**：裝備中的黃道武器會顯示再鑄進度視窗
- **本我**：裝備中的黃道武器·本我會顯示累積點數進度視窗，可選擇略過過場動畫、在圖示上疊加數字
- **光之加成回報**（預設關閉）：與社群伺服器同步目前哪些副本正處於「光之加成」期間，並可在裝備遺物時另外提示；此功能關閉時完全不會對外連線或回報任何角色資訊

## 使用

- `/pzodiac` 開啟設定視窗

## 安裝

在 Dalamud 設定的「自訂插件庫」加入
`https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json` 並啟用，
再從插件列表安裝。
